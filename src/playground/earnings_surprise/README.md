# Earnings Surprise Strategy 

**Main Idea**  
Long firms with strong earnings beats; short firms with earnings misses

**How**  
1. Calculate surprise: (Actual EPS - Consensus EPS) / |Consensus EPS|
2. Rank all stocks by surprise
3. Long top 10%, short bottom 10%

**Data Needed**  
- Earnings announcement dates
- Actual EPS
- Consensus EPS estimates  
- Daily stock prices
